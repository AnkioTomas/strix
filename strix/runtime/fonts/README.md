# Bundled CJK font for Strix sandboxes

`NotoSansSC-Regular.otf` is Noto Sans SC (Simplified Chinese) from
https://github.com/notofonts/noto-cjk (Subset OTF, Regular).

License: SIL Open Font License 1.1 — see `OFL.txt`.

Shipped so stock sandbox images without apt/network can still render Chinese
UI in Chromium screenshots. Staged into the scan workspace at runtime by
`strix.runtime.cjk_fonts`.
